# تعاونی مارکت

### فروشگاه اختصاصی تعاونی‌ها

تعاونی مارکت یک پلتفرم یکپارچه برای فروش اختصاصی به اعضای تعاونی‌ها، ایجاد فروشگاه مستقل برای هر تعاونی، خرید ویژه و توسعه خدمات و خرید اقساطی آسان است.

## ساختار اولیه

- `index.html` — صفحه اصلی
- `assets/css/` — استایل‌ها
- `assets/fonts/` — فونت‌های محلی
- `assets/images/` — تصاویر و هویت بصری
- `assets/js/` — اسکریپت‌های رابط کاربری
- `pages/` — صفحات داخلی
- `components/` — اجزای قابل استفاده مجدد
- `data/` — داده‌های ساختاریافته اولیه
- `docs/` — مستندات محصول و معماری

## مسیر توسعه

تعاونی شاپ در فاز نخست به‌عنوان بخش فروش کالاهای مصرفی و خرید روزانه در داخل تعاونی مارکت تعریف می‌شود و در آینده، در صورت رشد کافی، قابلیت تبدیل شدن به برند مستقل را خواهد داشت.
