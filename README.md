# تعاونی مارکت

### فروشگاه اختصاصی تعاونی‌ها

**تعاونی مارکت — فروشگاه اختصاصی تعاونی | سامانه یکپارچه خرید، اعتبار و خدمات اعضای تعاونی‌ها**

تعاونی مارکت یک پلتفرم یکپارچه برای فروش اختصاصی به اعضای تعاونی‌ها، ایجاد فروشگاه مستقل برای هر تعاونی، خرید ویژه، طرح‌های اختصاصی، اعتبار خرید و توسعه خدمات اعضا است.

## وضعیت پروژه

این مخزن نسخه اصلی استاتیک و قابل توسعه رابط کاربری و جریان‌های اولیه تعاونی مارکت را نگهداری می‌کند. **شاخه `main` مرجع اصلی پروژه و مبنای ادامه توسعه است.**

برای مشاهده دقیق اینکه پروژه در چه مرحله‌ای قرار دارد و ادامه کار باید از کجا انجام شود، ابتدا این سند را ببینید:

- `docs/CURRENT-STATUS.md` — وضعیت فعلی، آخرین تغییر، بخش‌های انجام‌شده و کارهای بعدی
- `docs/PROJECT-PLAN.md` — نقشه جامع محصول، معماری و برنامه توسعه

## آخرین وضعیت تثبیت‌شده

آخرین نسخه ثبت‌شده در `main` شامل تثبیت واکنش‌گرایی هدر و منوی موبایل است:

- هدر در موبایل حفظ می‌شود و متناسب با نمایشگر کوچک تنظیم می‌شود.
- منوی ناوبری بالای دسکتاپ در موبایل مخفی می‌شود.
- منوی موبایلی پایین صفحه جایگزین منوی بالای دسکتاپ است.
- لوگو، عنوان، جستجو و سبد خرید در هدر موبایل باقی می‌مانند.

## صفحات اصلی موجود

- `index.html` — صفحه اصلی
- `about.html` — درباره ما
- `store.html` — فروشگاه
- `product.html` — صفحه محصول
- `cart.html` — سبد خرید
- `login.html` — ورود
- `account.html` — حساب عضو
- `order.html` — ثبت سفارش
- `orders.html` — سفارش‌ها
- `payment.html` — پرداخت
- `preinvoice.html` — پیش‌فاکتور
- `receipt.html` — رسید
- `special-plans.html` — فهرست طرح‌های ویژه
- `special-plan.html` — صفحه اختصاصی هر طرح

## داده و دارایی‌ها

- `assets/css/` — استایل‌ها
- `assets/fonts/` — فونت‌های محلی پروژه
- `assets/images/` — تصاویر و هویت بصری
- `assets/js/` — اسکریپت‌های رابط کاربری
- `assets/data/special-plans.json` — داده‌های ساختاریافته طرح‌های ویژه

## مسیر توسعه

تعاونی مارکت در فاز نخست به‌عنوان یک پلتفرم فروش، اعتبار و خدمات اختصاصی جامعه تعاونی توسعه می‌یابد. در مراحل بعدی، رابط کاربری فعلی به Backend، API و پایگاه داده متصل خواهد شد تا اعضا، تعاونی‌ها، سفارش‌ها، طرح‌ها، اعتبار و پرداخت‌ها به‌صورت واقعی مدیریت شوند.

**قاعده ادامه توسعه:** مبنای کار `main` است. ایجاد شاخه‌های جانبی یا تغییرات غیرمرتبط بدون درخواست مستقیم انجام نشود.
